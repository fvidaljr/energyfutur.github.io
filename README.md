# Energy Futur

Sitio web de Energy Futur, orientado a ahorro energético (energía solar).

Proyecto generado con [Angular CLI](https://github.com/angular/angular-cli) versión 14.0.2.

## Estructura del proyecto

- `navbar` — barra de navegación
- `home` — página de inicio
- `servicios` — sección de servicios
- `nuestra-historia` — sección "Nuestra historia"

## Servidor de desarrollo

Ejecutá `ng serve` para levantar un servidor de desarrollo. Navegá a `http://localhost:4200/`. La aplicación se recarga automáticamente al modificar los archivos fuente.

## Generación de código

Ejecutá `ng generate component nombre-componente` para generar un nuevo componente. También podés usar `ng generate directive|pipe|service|class|guard|interface|enum|module`.

## Build

Ejecutá `ng build` para compilar el proyecto. Los artefactos de build se guardan en el directorio `dist/`.

## Tests unitarios

Ejecutá `ng test` para correr los tests unitarios vía [Karma](https://karma-runner.github.io).

## Tests end-to-end

Ejecutá `ng e2e` para correr los tests end-to-end. Para usar este comando primero necesitás agregar un paquete que implemente capacidades de testing e2e.

## Más ayuda

Para más ayuda con Angular CLI, usá `ng help` o visitá la [referencia de comandos de Angular CLI](https://angular.io/cli).
